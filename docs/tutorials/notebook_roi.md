# ROI Analysis Example

After preprocessing (outside of the pipeline), you can use a Region of Interest (ROI) analysis to average datapoints across selected channels and/or time windows. The ROI example notebook guides you through defining these selections and calculating their averages.

## Workflow

1. Start with a preprocessed data file.
2. In the [ROI example notebook](https://github.com/CentreForDigitalHumanities/BioPAP/blob/main/examples/example_ROI_averaging.ipynb), choose the channels and, if needed, the time windows to include in each ROI.
3. Run the analysis to export the ROI averages to a CSV file.
4. Load the CSV into your preferred analysis software for further analysis or visualization.

The notebook is intended as an example. Adapt the channel groups and time windows to suit your study or analysis.
